The Problem

Autonomous systems act on what they believe.
The belief is usually wrong.

Every autonomous AI runtime faces the same structural failure: components report their own state, and the system trusts those reports without independent verification.

⚠

Self-report diverges from runtime truth

A tool registers as available but fails in the live environment. A route exists in code but never produces a real output. Work is archived as complete while the evidence chain is still open.

🔁

Stale evidence drives live decisions

94% of autonomous decisions in a working runtime were made using evidence that was no longer current. The system continued acting as though the last known state was still true.

📋

Completion ≠ closure

Recorded activity creates apparent progress without satisfying the causal prerequisites for actual completion. The log says done. The work is not done.

🔒

No framework governs the gap

Existing systems verify task outputs, preserve provenance, or enforce action policies. None reconstruct operational truth about the runtime itself from independent causal evidence.

Nova

A runtime that derives its own truth

Nova is a local AI runtime that works continuously — governing its own operation from evidence, not assumption.

Evidence-derived operational state

Nova reconstructs its own operational state from independent runtime artifacts — process heartbeats, tool output records, causal dependency chains, and evidence ledger entries — rather than accepting component self-declarations.

A component that says it is running must prove it. A task that says it is complete must show its causal chain.

Research

Phase I: Evidence-Derived State Protocol

Three technical problems. One mechanism. Measured against a real failure corpus.

Problem 01

Evidence-State Derivation

Reconstruct operational state from heterogeneous runtime artifacts — process records, tool output logs, causal dependency chains, validity intervals — of differing types, ages, and reliability.

Problem 02

Causal Closure

Determine whether an evidence chain satisfies all causal prerequisites for autonomous task completion. State transitions permitted only when required evidence relations are satisfied.

Problem 03

Live Semantic Verification

Determine whether a registered capability produces the required real-world effect — not merely that it exists structurally. Classify routes as live-complete, evidence-dead, or absent.
